# Security Policy

## Supported version

Security and integrity fixes apply to the latest version on `main`.

## Reporting

For a security-sensitive problem, use GitHub's private vulnerability reporting
or contact the repository owner privately. Do not open a public issue containing
credentials, private filesystem paths, or other sensitive information.

This project contains static pet assets and local installation scripts. Reports
about unsafe installation behavior, path traversal, unexpected file overwrite,
or workflow supply-chain risk are in scope.
